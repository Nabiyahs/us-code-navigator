# 🏗️ US CODE NAVIGATOR

미국 건축 및 소방 코드 탐색 도구에 오신 것을 환영합니다.

!!! info "사용 목적"
    이 문서는 미국 건축 및 소방 관련 코드를 효율적으로 탐색하고
    관련 조항을 빠르게 찾을 수 있도록 구성되었습니다.

## 📚 사용 가능한 코드

=== "건축 코드"

    ### IBC 2024
    **International Building Code**

    미국 건축 코드의 기본이 되는 국제 건축 규정

## 🔍 빠른 검색

상단의 검색 창을 사용하여 키워드로 빠르게 검색할 수 있습니다.

**검색 팁:**

- 영문 키워드: `fire resistance`, `sprinkler`, `occupancy`
- 한글 키워드: `내화성능`, `스프링클러`, `용도`
- 섹션 번호: `703`, `307`, `414`

## 📖 자주 찾는 섹션

### 건축 관련

!!! example "인기 섹션"

    - [**Fire Resistance Rating**](ibc-2024/section-703.md) - 내화성능 (IBC 703)
    - [**High-hazard Group H**](ibc-2024/section-307.md) - 고위험시설군 (IBC 307)
    - [**Mezzanine**](ibc-2024/section-202.md#mezzanine) - 메자닌 중층 (IBC 202)
    - [**Hazardous Materials**](ibc-2024/section-414.md) - 위험물질 (IBC 414)

### 소방 관련

!!! example "인기 섹션"

    - **Sprinkler Design** - 스프링클러 설계 (NFPA 13 Chapter 11)
    - **Standpipe Requirements** - 옥내소화전 요구사항 (NFPA 14 Chapter 5)
    - **Fire Pump Installation** - 소방펌프 설치 (NFPA 20)

## 📋 사용 방법

!!! tip "이 문서 활용하기"

    1. **브라우징:** 왼쪽 메뉴에서 원하는 코드와 챕터 선택
    2. **검색:** 상단 검색창에서 키워드 입력 (Ctrl/Cmd + K)
    3. **링크 이동:** 관련 섹션 링크를 클릭하여 빠르게 이동
    4. **북마크:** 자주 찾는 페이지는 브라우저 북마크에 저장
